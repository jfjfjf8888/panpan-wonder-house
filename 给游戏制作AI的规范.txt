# 八、manifest.json 要求

必须按照以下格式生成：

```json
{
  "schemaVersion": "1.0",
  "id": "game-slug",
  "slug": "game-slug",
  "title": "游戏中文名称",
  "shortDescription": "不超过60字的一句话游戏介绍。",
  "description": "不超过500字的完整游戏介绍。",
  "version": "1.0.0",
  "author": "PanPan Lab",
  "entry": "index.html",
  "cover": "cover.webp",
  "icon": "icon.png",
  "tags": ["休闲", "益智"],
  "orientation": "any",
  "controls": ["touch", "mouse", "keyboard"],
  "display": {
    "aspectRatio": "16:9",
    "minWidth": 320,
    "maxWidth": 1920,
    "supportsFullscreen": true
  },
  "permissions": {
    "audio": true,
    "storage": true,
    "fullscreen": true,
    "networkDomains": []
  },
  "analytics": {
    "enabled": true
  },
  "adCapabilities": {
    "banner": false,
    "interstitial": true,
    "rewarded": true
  }
}
```

字段规则：

* `id`：使用小写英文、数字和短横线，发布后永久不变。
* `slug`：通常与 id 相同。
* `title`：2 至 30 个字符。
* `shortDescription`：最多 60 个字符。
* `description`：最多 500 个字符。
* `version`：使用 `1.0.0` 形式。
* `entry`：必须指向真实存在的入口文件。
* `cover`：必须指向真实存在的 WebP 文件。
* `tags`：最多 5 个。
* `orientation`：只能是 `portrait`、`landscape` 或 `any`。
* `controls`：只填写游戏实际支持的操作方式。
* `networkDomains`：默认必须为空数组。
* `adCapabilities`：只是预留能力，当前网站不会真正播放广告。

制作新游戏时版本号使用：

```text
1.0.0
```

更新已有游戏时：

* id 不得改变。
* slug 不得改变。
* 根据改动提高版本号。
* 修复问题可以从 `1.0.0` 更新到 `1.0.1`。
* 增加功能可以更新到 `1.1.0`。
* 大规模改版可以更新到 `2.0.0`。

# 九、网站通信协议

游戏运行在网站 iframe 内，必须通过 `window.parent.postMessage()` 与网站通信。

所有游戏发送的消息必须使用以下公共结构：

```javascript
{
  source: "panpan-game",
  version: "1.0",
  type: "事件名称",
  payload: {}
}
```

发送消息时使用：

```javascript
window.parent.postMessage(
  {
    source: "panpan-game",
    version: "1.0",
    type: "GAME_READY",
    payload: {}
  },
  "*"
);
```

必须支持以下事件。

## 1. GAME_READY

游戏资源完成加载，并且可以开始操作时发送一次：

```javascript
sendToHost("GAME_READY", {
  gameVersion: "1.0.0"
});
```

## 2. GAME_START

玩家正式开始一局时发送：

```javascript
sendToHost("GAME_START", {
  mode: "normal"
});
```

不要在网页刚加载时发送，必须在玩家真正开始游戏时发送。

## 3. GAME_PAUSE

游戏暂停时发送：

```javascript
sendToHost("GAME_PAUSE", {});
```

## 4. GAME_RESUME

游戏恢复时发送：

```javascript
sendToHost("GAME_RESUME", {});
```

## 5. SCORE_UPDATE

分数发生重要变化时发送：

```javascript
sendToHost("SCORE_UPDATE", {
  score: 300
});
```

不要每一帧发送。

## 6. LEVEL_COMPLETE

完成关卡时发送：

```javascript
sendToHost("LEVEL_COMPLETE", {
  level: 3,
  score: 600
});
```

## 7. GAME_END

一局结束时必须发送：

```javascript
sendToHost("GAME_END", {
  score: 850,
  durationSeconds: 92,
  result: "completed"
});
```

`result` 可以使用：

```text
completed
failed
quit
timeout
```

## 8. GAME_ERROR

发生无法正常继续的错误时发送：

```javascript
sendToHost("GAME_ERROR", {
  code: "RESOURCE_LOAD_FAILED",
  message: "背景图片加载失败",
  fatal: true
});
```

# 十、game-bridge.js 要求

必须创建 `js/game-bridge.js`，集中封装网站通信，不要在游戏各处散落大量 `postMessage` 代码。

至少实现：

```javascript
(function () {
  "use strict";

  const HOST_SOURCE = "panpan-host";
  const GAME_SOURCE = "panpan-game";
  const PROTOCOL_VERSION = "1.0";

  let hostConfig = {
    muted: false,
    adsEnabled: false
  };

  function send(type, payload) {
    window.parent.postMessage(
      {
        source: GAME_SOURCE,
        version: PROTOCOL_VERSION,
        type,
        payload: payload || {}
      },
      "*"
    );
  }

  function onHostMessage(event) {
    const message = event.data;

    if (!message || message.source !== HOST_SOURCE) {
      return;
    }

    if (message.version !== PROTOCOL_VERSION) {
      return;
    }

    switch (message.type) {
      case "HOST_INIT":
        hostConfig = {
          ...hostConfig,
          ...message.payload
        };

        window.dispatchEvent(
          new CustomEvent("panpan:host-init", {
            detail: hostConfig
          })
        );
        break;

      case "HOST_PAUSE":
        window.dispatchEvent(new CustomEvent("panpan:pause"));
        break;

      case "HOST_RESUME":
        window.dispatchEvent(new CustomEvent("panpan:resume"));
        break;

      case "AUDIO_CHANGE":
        hostConfig.muted = Boolean(message.payload?.muted);

        window.dispatchEvent(
          new CustomEvent("panpan:audio-change", {
            detail: {
              muted: hostConfig.muted
            }
          })
        );
        break;

      case "AD_RESULT":
        window.dispatchEvent(
          new CustomEvent("panpan:ad-result", {
            detail: message.payload || {}
          })
        );
        break;
    }
  }

  window.addEventListener("message", onHostMessage);

  window.PanPanGame = {
    send,
    ready(payload) {
      send("GAME_READY", payload);
    },
    start(payload) {
      send("GAME_START", payload);
    },
    pause(payload) {
      send("GAME_PAUSE", payload);
    },
    resume(payload) {
      send("GAME_RESUME", payload);
    },
    score(payload) {
      send("SCORE_UPDATE", payload);
    },
    levelComplete(payload) {
      send("LEVEL_COMPLETE", payload);
    },
    end(payload) {
      send("GAME_END", payload);
    },
    error(payload) {
      send("GAME_ERROR", payload);
    },
    requestAd(payload) {
      send("AD_REQUEST", payload);
    },
    getHostConfig() {
      return { ...hostConfig };
    }
  };
})();
```

`index.html` 必须在游戏主脚本之前引入：

```html
<script src="./js/game-bridge.js"></script>
<script src="./js/game.js"></script>
```

# 十一、广告兼容要求

当前网站不会实际接入广告，但游戏需要预留兼容能力。

游戏可以请求：

* 插屏广告 `interstitial`。
* 激励广告 `rewarded`。

请求示例：

```javascript
window.PanPanGame.requestAd({
  format: "rewarded",
  placement: "continue_after_failure",
  requestId: "rewarded-001"
});
```

网站可能返回：

```text
completed
skipped
no_fill
error
disabled
```

只有收到：

```text
completed
```

时才发放激励奖励。

收到以下结果时，游戏必须正常继续，不能卡死：

```text
disabled
no_fill
error
skipped
```

当前广告默认关闭，因此游戏必须完整支持无广告运行。

# 十二、本地存档要求

需要保存设置、关卡或最高分时，可以使用 localStorage。

所有键必须增加游戏命名空间：

```text
panpan_game_{gameId}_{key}
```

示例：

```javascript
localStorage.setItem(
  "panpan_game_memory-card_high-score",
  "1000"
);
```

不得使用过于通用的名称，例如：

```text
score
settings
data
```

读取损坏或不存在的存档时必须使用默认值，不能导致游戏无法启动。

# 十三、错误处理要求

游戏必须处理：

* 图片加载失败。
* 音频加载失败。
* 存档内容损坏。
* 浏览器不支持某个 API。
* Canvas 初始化失败。
* 未捕获 JavaScript 异常。
* 手机横竖屏变化。
* 页面切换到后台。
* 用户快速重复点击。

至少监听：

```javascript
window.addEventListener("error", function (event) {
  window.PanPanGame?.error({
    code: "UNHANDLED_ERROR",
    message: event.message || "未知错误",
    fatal: false
  });
});

window.addEventListener("unhandledrejection", function (event) {
  window.PanPanGame?.error({
    code: "UNHANDLED_PROMISE_REJECTION",
    message: String(event.reason || "未知异步错误"),
    fatal: false
  });
});
```
